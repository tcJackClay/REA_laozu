# REA_laozu

《我要当老祖》浏览器复刻开发项目，当前包含山门、主线及游历系统，最新更新为游历招生入口第十版。

## 本地启动

安装 Node.js，在仓库根目录运行：

```sh
node outputs/laozu-web/server.cjs
```

打开 http://127.0.0.1:5173/ 。Windows 也可双击 `outputs/laozu-web/启动游戏.cmd`。页面使用浏览器本地存档。

## 当前状态

## 目录

- `outputs/laozu-web/`：可运行网页、脚本、样式和使用中的素材。
- `work/alignment-v10/test-admission.cjs`：招生入口回归脚本。
- `work/alignment-v9/test.cjs`：坐标与主线回归脚本。

测试脚本保留开发环境路径，跨机器运行需调整其中 Playwright 依赖路径，并先启动本地服务。上一次开发验证为入口 30 项、回归 39 项通过，不能替代原版实机数值验证。

仓库不收录原 APK、模拟器数据、账户采集日志、工具虚拟环境、历史压缩包及临时缓存。说明中的部分本地证据路径因此仅在原开发机器可用。
