## 当前融合规则
- 已有 23 个室外道路配置按原章节、道路次序推进；当前道路毕业并确认结算后开放下一条。每章所有室外道路毕业后解锁该馆；战败不推进。
- 道馆结算胜利后获得徽章，开放下一章。可重复挑战，但不重复授予徽章、收藏或基因奖励。
- 初始可进入 1 号道路；1号高等级、森林高等级和7/8号复访配置分别受自己的章节与前置道路限制，地图气泡只列已解锁等级。
