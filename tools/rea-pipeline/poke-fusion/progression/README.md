- 道馆结算胜利后获得徽章，开放下一章。可重复挑战，但不重复授予徽章、收藏或基因奖励。

## 三只出战选择（覆盖单只道馆挑战）
- 点已解锁道馆弹出黑色选择层，初始0/3；选择顺序即出战顺序。可点击已选卡片/槽位取消；满3只才可确认，不能重复同一个收藏UID，允许同物种不同个体。
- 关闭/Escape不创建run，不消耗资源。收藏不足3只时可打开，但无法确认。
- 确认后立即进入战斗，每只保留自身毕业背包。倒下自动接替，保留当前敌人HP/时间；新伙伴招式在600ms后启动。全部倒下才失败。
- 队伍顺序、当前队员、各自HP/背包随run保存。刷新恢复原队伍，不重新选择，不改写收藏个体。旧单只挑战存档可完成，但新挑战必须三只。
