# 随机事件三选一与进化

## 已确认规则
- 每场胜利后先随机三个事件，而不是固定三类资源按钮；选择一个，结算后回背包，前进丢弃未入包物品。
- 每次仍获得原有2抽取点与2等级。事件附加收益或消耗只执行一次。候选、选中结果、进化选择均入存档，刷新不重抽。
- 进化以PokeCatch EVOLUTIONS等级为准：1→2 Lv16、2→3 Lv32；4→5 Lv16、5→6 Lv36；7→8 Lv16、8→9 Lv36。当前可抽取这三条初始伙伴谱系。

## 原始证据与融合边界
- APK UISelectOne.OptionCount默认3，初次更新GetAvailableItems，选择时回调并关窗。UIGodExam有普通准备、启动、失败/成功结果与确认节点。摘录及源哈希在此目录。
- 本版沿用三选一和阶段结果确认的流程，不复制雷劫伤害、丹药与失败概率。没有把宝可梦进化包装成原APK玩法原样复现。
- 七类事件均匀抽取三个不同选项；商人仅在抽取点足够时进入候选。文案与奖励属于融合设计，非原APK事件数值。
- 招式特训：本谱系高级招式2×2；遗落行囊：学习装置2×1；采集：橙橙果1×1两个；休息：恢复35%最大HP；协助研究：抽取点+3；商人：抽取点-2换两个学习装置；深入密林：扣最大HP10%（最低留1）换招式+树果。
- 橙橙果和学习装置沿用实际战斗效果，学习装置同类不叠加，不增设新装备规则。直接恢复和点数奖励即时到账。
- 首次出发或战后背包前进时检查进化，战斗进行中不打断。高等级路线可连续确认两阶进化。暂不进化后同节点不重复弹出，下个战后节点可再选择。
- 进化更新物种、属性、种族基础与伤害，最大生命按新旧种族HP比缩放，当前生命比例保留；携带道具保留；遗忘全部已有招式，从新形态当前等级可学的攻击招式中随机抽取一个2×1卡块，自动放入可用格；无合适空格则放到背包侧边，必须入包才能前进。变化招式尚未实现，暂不进入池。收藏记录进化后的物种。HP缩放属于本地融合规则。
- 同一场景覆盖面板；沿用原PokeCatch素材和黑色主题；无新增说明页。

## 验证
- test-poke-events.cjs：648项，七事件、成本/收益、重复提交防护、三谱系进化阈值/实际伤害、生命比例、延期与连续进化。
- test-poke-events-ui.cjs：17项，首场真实时钟获胜到三选一、刷新、三屏宽、奖励到收藏、跳过进化、结果恢复与新身份战斗。
- 路线69局完整毕业，146项；原模型27项，背包29项，冒险12项，抽取13项，路线UI35项，场景139项。
- 浏览器截图为模拟手机尺寸，不是实体手机验证。没有采集新的原APK运行录像。

进化采用与事件相同的二选一卡片：进化（遗忘全部招式，随机一个）/保持形态（保留原招式）。随机结果在确认时生成并保存，结果页展示招式，刷新不重新生成。主题33项及HP64项回归通过。
