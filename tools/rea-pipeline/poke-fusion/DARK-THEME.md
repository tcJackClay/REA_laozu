# PokeCatch 黑色主题对齐

2026-10-23。用户明确要求全部画面/元素风格对齐 PokeCatch 黑色主题，全部图形使用其已有素材。此次只改视觉及按钮样式类，不改模型、存档键、掉落或经济规则。

## 原始依据与提取

固定输入：`evidence/source/bundle/app.4cbef38437.css`，来自用户提供的pokecatch-reference研究包；参考原站黑色模式的09-adventure-running、10-team截图。没有将原站的桌面导航布局覆盖到当前竖屏骨架。

`build-poke-theme.py` 提取38段原CSS规则，包括4段嵌入字体声明（Jersey 10/15的不同字符子集）、精灵球背景纹理、卡片扫描线/精灵球纹理、像素控制器多层边框/阴影和黑色主题变量。18种属性色来自原TYPES.json。

原黑色变量为背景#141826、下凹区#10131f、面板#1c2030/#252a3d、边线#333a52、正文#eef1f8、辅助字#9aa3bb、选中红#e3353b、行动黄#ffcb05。这些是来源值，不是临时手配近似色。

来源及字符范围见[主题清单](../../../outputs/laozu-web/poke/theme-manifest.json)。中文字符由系统字体回退，源Jersey只含其原字符范围，不声称拥有不存在的原中文像素字体。

源主题在`source-theme.css`，适配器在`dark-theme.css`；原`style.css`继续负责几何布局。通过加载顺序和作用域将新主题应用到所有现有画面，未加载旧修仙运行入口。

## 区域更新

- 顶部身份和钱包、底部六导航：暗色分层、原图标、红色像素选中态。
- 据点：使用原镇景，入口/任务/标题改暗色面板，中心行动按钮使用原黄色像素样式。
- 抽取：原精灵球图像，原黑色背景纹理、字体和行动按钮。
- 战斗：保持原林间场景，生命、属性、路线和状态改暗色HUD。
- 奖励、背包：去掉绿色底板；暗色网格、原卡片纹理、对应原属性色、原携带道具图像。
- 结算、收藏、研究、道馆整备、图鉴：统一暗面板、卡片、字体、统计和返回按钮。

原场景图保留其彩色像素内容，与原站黑色主题下的彩色战斗场景一致；没有自行生成夜景、建筑或图标。像素边框和精灵球SVG底纹来自原CSS，不是重新绘制。

## 验证

`node tools/rea-pipeline/test-poke-theme.cjs`：33项通过，检查原主题变量、字体加载、所有导航页背景/文字/图像路径、原像素按钮、原属性色、奖励板/格位和320/360/450宽边界，无脚本/资源错误。收藏、道馆整备、奖励几何使用明确的隔离模型fixture；这不是原站运行采集。

`test-poke-browser.cjs`：最终主题下完整闭环30项回归，涵盖首场自然计时、真实拖拽、旋转、奖励返回、第二战、收藏、刷新和第二轮扣点。不是对道馆实战等未实现玩法的验证。

官方develop-web-game客户端主页冒烟执行并查看canvas截图与状态；全页界面以专项截图为准。此次未修改model.js，不把视觉更新包装成新玩法实现。
