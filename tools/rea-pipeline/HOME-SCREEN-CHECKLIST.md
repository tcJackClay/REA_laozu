# 山门主画面替换与验收总清单

更新：2026-10-22。检查基线：`e0473a7`。本轮建立清单，不把列出的缺口当成已经修复。

## 如何使用

- **接入**：入口或资源存在，不代表视觉、功能全通过。
- **需修**：已在代码或浏览器复现缺口/错误。
- **待核**：原节点存在，但解锁、活动、折叠或平台条件仍需定位，不能直接全部显示。
- 只有同时通过「图形/位置 → 显示条件 → 点击目的页 → 操作生效 → 返回/刷新」五项，才勾选验收完成。复用原图不能单独作为验收依据。
- 优先顺序：P0 主画面错误与可见死入口；P1 功能页和条件显示；P2 活动/社交/动态扩展。数值继续允许近似。

## 本轮实际证据

当前运行的是 `aligned-stage.js` 的 `renderHome()`，不是 `game.js` 中旧的 `renderSect()`。两套代码仍同时存在，不能只修旧分支。

自动核对 **557 个原始节点**（UIMain 516 + UIMainNavs 41），其中 **55 个原始交互候选节点**：当前可见23个，**14个可见但没有网页点击绑定**；32个当前隐藏。可见指DOM布局可见，尚不保证没有遮挡或完全处于视口内。这里统计的是节点，不是55个独立系统；不将条件隐藏全部算作错误。

## 检查与更新方式

1. 启动 `outputs/laozu-web/server.cjs`。
2. 在仓库根目录运行 `node tools/rea-pipeline/audit-home-screen.cjs`，重新生成主画面截图、557节点清单与统计。
3. 运行 `node tools/rea-pipeline/audit-home-navigation.cjs`，重新核对六项导航；使用隔离浏览器，不操作用户存档。
4. 每修一个区域更新对应编号、源方法/资源、截图及操作验证；自动表中的“有绑定”不能直接转换成“已完成”。

本清单覆盖当前提取的主Prefab、底栏及已知动态区域，不声称已穷尽整个APK所有窗口或所有运营活动。动态生成内容继续记入S11，下一轮应补对应配置和运行状态；不得用“截图没出现”直接删掉原功能。
