- 宗门供奉、升级、收徒、出战弟子选择与修炼，原有乾坤袋整理、旋转、出售、合成。
- 游历初始配置：入学档案 5 点、四项属性，主修/辅修功法、两位随行长老及空长老确认。
- 原包 WanderPath 1001 的 20 个节点：剧情、灵宠选择、装备机缘、普通战、神通、精英、疗伤、首领、血契换宝、渡劫、老祖传功、终结。

- 未领取法宝浮在上方场景；拖入棋盘、移动、旋转、拖回池、无效落点回池、支持配方的重叠合成、按钮合成。
- 分批领取、普通剩余法宝重铸收束、品质≥5 时放弃确认；已入包法宝保留，未领取奖励仅清理当前批次。刷新恢复当前批次与战斗快照，最终奖励只入账一次。

## 操作

奖励法宝直接拖到下方 6 行 7 列棋盘；也可先选中再点格。选中后按 R 或“旋转”。右键法宝或使用“回池”收回；拖出棋盘也会回池。底部“储物袋”展开原有闲置法宝；再次点击收起。

点击圆形“继续”推进事件或领取下一批；有品质≥5 的未入包法宝时才需确认跳过；普通法宝按重铸收束后继续。战斗中圆形按钮可跳过动画并计算正常战果。弹窗需完成相应选择。F 可切换全屏。
